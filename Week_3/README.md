# Project Overview

This project focuses on analyzing the Superstore sales dataset using SQL and Python. The primary objective is to demonstrate practical SQL skills by loading raw business data into a SQLite database, normalizing the dataset into multiple tables, and extracting meaningful business insights through advanced SQL queries.

The analysis covers customer behavior, sales performance, ranking techniques, window functions, Common Table Expressions (CTEs), and subqueries. The final outcome provides actionable insights that can help businesses improve customer retention, optimize revenue generation, and make data-driven decisions.

# Data Loading Process

The dataset is first loaded into a Pandas DataFrame and then inserted into a SQLite database.

Steps performed:

1. Read CSV file using Pandas.
2. Create SQLite database connection.
3. Load the entire dataset into a raw table named `superstore_raw`.
4. Verify successful loading of records.

This creates a centralized database structure for executing SQL queries efficiently.

# Key Business Insights

## 1. Revenue Is Driven by a Small Group of Customers

A relatively small percentage of customers contributes a significant portion of total sales. Maintaining strong relationships with these customers is critical for sustaining revenue growth.

### Recommendation

- Create loyalty programs.
- Offer exclusive benefits.
- Provide personalized experiences.

---

## 2. Customer Retention Requires Improvement

Several customers appear to make only one purchase and never return.

### Recommendation

- Introduce reward programs.
- Send personalized follow-ups.
- Run targeted email campaigns.

---

## 3. High Discounts Do Not Always Improve Profitability

Products with larger discounts often produce lower profit margins.

### Recommendation

- Review discount policies.
- Optimize pricing strategies.
- Focus on profit-based promotions.

---

## 4. Regional Performance Varies Significantly

Some regions outperform others in both sales and profitability.

### Recommendation

- Study successful regions.
- Replicate best-performing strategies.
- Develop localized marketing campaigns.

---

## 5. High-Value Orders Are Concentrated in Specific Categories

Technology and Furniture categories frequently generate larger order values.

### Recommendation

- Increase marketing investment in these categories.
- Promote premium products.
- Expand high-performing product lines.
